Module site 

Source
Expand description

The static site generator, which builds _site from the pages compiled into this crate.

Site::load reads every page’s front matter, and Site::build renders them and writes the site:

  1. Pages with template tags, like ramblings, are rendered with askama first, from templates build.rs declares.
  2. Every page’s Markdown is rendered to HTML by Markdown.
  3. The page is wrapped in its Layout, and then the site’s default one, with the header and nav.
  4. The Markdown, wrapped in its layout but not the default one, is published next to the HTML, like /ramblings/foo.md, for the terminal view. So is site.json, the Index.

Everything else in the repository that’s part of the site, like images and CSS, is copied over as it is. The fortunes get their strfile databases, and TikZ figures are drawn to SVG.
