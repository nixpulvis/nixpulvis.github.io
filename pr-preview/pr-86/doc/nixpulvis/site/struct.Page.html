Expand description

A page, with its front matter read and its Markdown rendered.

Fields§

§source: &'static Source§url: String

Where it’s published, from the site’s root, like /ramblings/2018-02-05-hello-world or /about.html.

§collection: Option<&'static Collection>§front: FrontMatter§date: Option<NaiveDate>

From the front matter or the file’s name. Undated pages in a collection sort as if they were written at build time.

§markdown: String

The page’s Markdown, after its template tags have been rendered, if it has any.

§content: String

The Markdown, rendered to HTML, without any layout.

§excerpt: String

The first paragraph, rendered, for pages in a collection.
