in progress Galos

  • https://github.com/nixpulvis/galos

Galos is a map of the galaxy in Elite: Dangerous, built from what players report as they fly, and compared against the sky as it’s actually measured from Earth. It started as a way to keep track of factions and systems, and slowly turned into a 3D map that can draw all of explored space without a database behind it.

How it Works

Elite’s galaxy arrives as a stream of events. Every commander running a tool like EDMC forwards what their game sees to EDDN, and Galos listens to that feed and keeps it in Postgres (with PostGIS for the positions). Dumps from Spansh and EDSM fill in the history that came before. Your own game writes a directory of journal files, and Galos reads those too, so the world and your own commander end up in one place.

From that data a builder derives a single spatial index, an octree written to disk in its own format. The map reads only that index. No database, no server, just a directory of files.

cargo run --release --bin galos -- ingest --from eddn --index ~/.galos_index
cd galos_map && cargo run --release -- --index ~/.galos_index

The Map

The map is written in Rust with Bevy. From far away it draws every known system as one glowing field, and as you fly in the systems separate into points, then named stars, then a system’s own planets at their real geometry. Planets are drawn where the game has carried them by now, run forward from whenever someone last scanned them, rather than where they happened to be at the time.

It can also route. The router builds a jump graph over the index, knows about neutron star “supercharge” highways, and can order a set of stops into a sensible trip.

The Real Sky

Elite’s galaxy is a procedural model of the Milky Way, seeded with real catalog stars near Sol. So the question is, how close is it? Galos reads published star catalogs and compares them against the game. The photometry crate works out magnitudes, temperatures and color, and a small CPU renderer draws a patch of sky, which is how the Big Dipper ends up as a golden test image.
