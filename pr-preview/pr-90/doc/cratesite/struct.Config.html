Expand description

A site’s settings.

Fields§

§title: &'static str

The site’s name, like nixpulvis.

§url: &'static str

Where it’s published, like https://nixpulvis.com, without a / at the end.

§description: &'static str

What the site is, for pages without a summary of their own.

§repository: Option<&'static str>

Where its source lives, like https://github.com/you/site, for links to each page’s source from the docs.

§collections: &'static [Collection]

Folders of pages of one kind, like ramblings or projects.

§exclude: &'static [&'static str]

Files and folders at the top of the crate that aren’t part of the site, like Cargo.toml and src. target and names starting with _ or . never are.

§unlisted: &'static [&'static str]

Folders whose pages are published but left out of the docs.

§keep: &'static [&'static str]

What a build leaves in the destination, for things built another way, like doc for the crate’s own docs.

§tikz_preamble: &'static str

LaTeX put in every TikZ figure’s document, for packages and TikZ libraries, like \usepackage{tikz-cd}.

pub fn permalink(&self, path: &str) -> String

Where the page in the file at path is published, from the top of the crate, unless its front matter gives a permalink.

Pages in a collection go where the collection says. Others keep their path, as .html, except an index which is its folder. Files that aren’t Markdown keep their path as it is.
