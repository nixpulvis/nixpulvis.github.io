1//! [nixpulvis.com](https://nixpulvis.com), as a Rust crate.
2//!
3//! [`pages`] is the site itself. Every page is a Markdown file, and also a
4//! module, documented with the page, so those docs are another way to read
5//! the site. [`pages::ramblings`] holds the ramblings, [`pages::projects`]
6//! the projects, and so on, laid out like the site's URLs. Each page
7//! module's `PAGE` is the [`Source`] it was made from.
8//!
9//! The rest of the crate builds the site and browses it:
10//!
11//! - [`site`] builds the site with [cratesite], behind the `site` feature.
12//!   It reads the pages compiled into this crate and writes `_site`, the
13//!   HTML GitHub Pages serves, along with each page's Markdown and
14//!   `site.json`. Run it with `cargo site build`, or `cargo site serve`
15//!   while writing. [`CONFIG`] lays the site out.
16//! - [`tui`] is the terminal app, behind the `tui` feature, which the
17//!   `nixpulvis-tui` and `nixpulvis-web` crates host in a terminal and in
18//!   the browser. It reads the published Markdown over HTTP, so an
19//!   installed copy stays current.
20//! - [`index`] is `site.json`, which the generator writes and the terminal
21//!   app reads.
22
23mod config;
24pub mod index;
25#[cfg(feature = "site")]
26pub mod site;
27#[cfg(feature = "tui")]
28pub mod tui;

30pub use config::CONFIG;
31pub use cratesite::Source;
